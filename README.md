## 🌐 Portfolio Website

A responsive personal portfolio site lives in this repo (`index.html`, `styles.css`, `script.js`) — no build step needed, just open `index.html` in a browser.

**Features:** dark/light mode, typing animation, scroll reveal, animated skill bars & counters, project filter, timeline, testimonials, contact form (opens email app), mobile menu.

**Customise:** edit your name, photo, projects and social links in `index.html`, and set your email in `MY_EMAIL` inside `script.js`.

**Publish free with GitHub Pages:** repo **Settings → Pages → Deploy from branch → `main` / root**.
