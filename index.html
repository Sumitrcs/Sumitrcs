About

Who I Am

I'm Sumit — Sumitrcs on GitHub — a developer based in Delhi. Half of my work is practical software for Indian businesses: GST invoicing, bank reconciliation, Tally Prime integration and GeM bid analysis. The other half is learning computer science by building it: a key-value database, an HTTP server and a compressor in Rust, a programming language, and a SQL engine.

Everything is open source, tested and documented, with CI on every repository. I care about correctness — exact money arithmetic in paise, time-zone and DST edge cases, crash recovery — and about code other people can read.
